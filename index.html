Louise Local n8n

Louise Local n8n is a personal automation application operated by Louise using a self-hosted n8n installation.

What the application does

The application connects the operator's Google account to workflows that organize spreadsheet data, record inquiries, and perform configured Google Sheets tasks. It uses Google Drive file information to locate and select spreadsheets.

Current use is personal learning and automation. The application is not offered as a public sign-up service. This website provides information about the application; it does not provide access to the automation editor.

Google account access

Google access requires the account holder's authorization. The requested permissions and data-handling practices are explained in the privacy policy.
